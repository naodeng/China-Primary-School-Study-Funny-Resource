# 一、三年级课程扩充与逐题审校设计

## 目标与范围

为小学一年级、三年级上下学期各增加语文、数学、英语课程。按教材册次注册完整可玩目录：语文每册 8 个单元，数学依册次目录注册正式单元及未编号综合实践，英语每册 6 个 Unit 与 2 个 Revision。共 12 册、105 个可玩条目。

按现行作者规范，每条目有基础至少 2 个任务、进阶 2 个任务、高阶 2 个任务；每个任务一场 20 分钟、8 道原创题。最低新增 630 个任务、5,040 道题。审校覆盖这 105 个条目的所有题目。

## 教材来源

- 每册优先用可从人教社完整核实的最新版学生书及目录。不能完整核实时，沿用项目已裁定的 TapXWorld 固定提交 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`；`sourceKind` 为 `tapx-fallback`，记录具体文件、人教社证据及已知差异。未知版次信息留空，不称其为最新版。
- 中文和数学目录以固定快照逐册核对；英语沿用现有二年级使用的人民教育出版社“一年级起点”序列，学校是否开课仍标记为 `unconfirmed`。
- 所有问题、提示和解释原创，不复制课文、教材插图或整段教材内容。

## 数据和运行时约定

- 保持 `grade-{1|3}/term-{1|2}/{subject}/{entry}/index.ts` 路径，复用现有三类课程构建器；构建器接受可选 `grade`，缺省值继续为 2，避免改写既有课程 ID。
- 正式单元、Revision 与综合实践使用稳定的规范 ID；所有生成的任务、场次、题目 ID 全局唯一。
- 每册元数据、目录注册表、课程内容和轻量进度 manifest 必须一一对应。基础任务完成语义及学习起点由现有成就逻辑提供。
- 审校台账覆盖新建 105 条目中的全部难度、任务、场次和题目；逐题检查答案唯一且正确、表述清楚适龄、来源主题一致、难度符合任务目标。数学复算算式与单位，英语核对拼写、词义、语法，语文核对字词和题意。修复记录包含完整题目 ID 和原因。

## 验收标准

1. 四个年级学期范围均出现语文、数学、英语，12 册来源元数据完整；英文路径及回退差异明确。
2. 新增 105 个条目：语文 32、数学 41、英语 32；全部注册目录与物理入口文件一致。
3. 至少 630 个任务、5,040 道题；各题答案引用有效，ID 唯一，每场 8 题。
4. 审校台账恰有每个新条目一行，题目总数和已审数等于实际题数，六个状态维度均为“完成”；所有修复均可追溯。
5. 轻量 manifest 的教材、目录、会话 ID 与实际课程一致；新增数学算式逐式复算。
6. 按项目说明运行所需测试、`npm run build` 与 `git diff --check`；最终检查工作区和全部差异，不提交或推送。
