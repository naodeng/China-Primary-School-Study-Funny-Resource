# 一年级、三年级题目全量审校报告

**审校日期：** 2026-10-16
**范围：** 一年级、三年级上下学期语文、数学、英语 105 个课程条目，覆盖基础、进阶、高阶各两项任务。
**教材依据：** [年级教材清单](grade-1-and-3-textbook-inventory.md)记录的 TapXWorld 固定快照和每个课程条目的 `sourceTopics`。
**可复用规则：** [课程内容分层审核规则](course-content-review-rules.md)

## 审核结果

从运行时课程数据导出全部 **5,040 道题**（105 个条目各 48 道），逐题核对题干、答案键、提示、解释、题型结构、所属主题和任务档位。再按不含 ID 与选项顺序的完整题目指纹检查同任务与同档两个任务之间的重复，并比较每个课程两项任务的三档难度差异。

| 检查项 | 结果 |
| --- | --- |
| 课程条目 / 题目 / 唯一 ID | 105 / 5,040 / 5,040 |
| 题型 | 选择 3,598；配对 210；分类 340；排序 526；算式 366 |
| 任务结构 | 每条目 3 个难度 × 2 个任务；每任务 1 场、8 题 |
| 结构与答案键 | 5,040 道题的选项、配对项、排序键、分类键、引用和子项 ID 检查无错误；课程及题目内共 22,753 个 ID 均唯一 |
| 算式复算 | 366/366 正确 |
| 完整重复题 | 同任务内和同档两个任务间均未发现；按题干、提示、解释、正确答案及题型内容比较，不计 ID 和选项顺序 |
| 分层差异 | 630 组同课程、同任务、跨难度比较均至少有 4/8 题位在完整内容上不同；任务目标也已分别核对 |

自动扫描发现有两组数学题使用相同的选项集合和正确答案，已人工复核为不同问题：一年级上册“位置”单元分别考查左右关系反向和面对面观察者的左右视角；三年级上册总复习分别求集合图的圈外人数和交集人数。题干、所求区域及推理目标均不同，未判为重复题。复用相同题型或共同答案标签本身不作为缺陷。

## 本轮确认并修复的问题

### 语文

- 一年级上册“汉语拼音（一）”补全教材清单中的单韵母、声母及 `y/w` 字母分类，并加入声调和拼读步骤练习。
- 一年级上册“汉语拼音（二）”补全复韵母、前后鼻韵母和整体认读音节覆盖；避免把整体认读音节拆读或当作词义解释。
- 一年级上册“汉语拼音（二）”把分类题限制为每题最多 8 张卡，超出的拼音卡转入配对题，仍覆盖目录列出的全部 34 项；“汉语拼音（一）”的说明也不再提前使用整体认读音节术语。
- 一年级上册“入学启蒙与识字”修正同属“身边环境”的两张字卡被重复列成两个分类标准的答案表述，并增加生成器回归检查。
- 三年级上册“校园生活”将“交流”归入表达活动，而非阅读方法。
- 三年级下册“奇妙的想象”高阶任务改为核对想象事物的特点是否一致、是否服务于用途，移除不适合本单元的观察线索表述。
- 调整生成器中跨难度重复题，使每个任务的每组难度比较至少有 4/8 个题位在题意、材料或推理动作上不同；修改后的完整题目指纹在每个任务内唯一。

### 数学

- 修复一年级上册“6～10 的认识和加减法”进阶任务二重复的 `0` 选项：`grade-1/term-1/math/unit-03/advanced/task-02/session-01/question-04`。
- 将一年级下册“摆一摆，想一想”改为按 2–5 枚棋子枚举十位、个位的全部有限组合，并覆盖数值表示、配对、排序和查漏；测试逐个核验组合数量和对应数值。
- 修复把完整排序题错误转换成“第一步是什么”的生成逻辑，改为保留原排序题并将完整正确序列设为答案。
- 三年级上册“长方形和正方形”移除提前出现的面积概念，并改成围绕周长与单条边长的题目；本册总复习同步去除随用的超前内容。三年级上册“分数的初步认识”主题登记补全“几分之几”，与目录条目对应；[教育部课程目录](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202304/W020230420309231498801.pdf)列有“认识几分之几”课程内容。
- 改进一年级上册计数、时钟与一年级下册分类练习，以及三年级倍数、分数、复式统计表练习的重复考点；三年级下册“搭配（二）”避免基础、进阶、高阶克隆同一题组。
- 修复三年级下册“搭配（二）”漏列三组饮料与点心组合却要求查漏的问题；题面现列出其余五组，答案唯一且解析说明补齐后的六种组合。

### 英语

- 一年级下册 Food 单元将肯定回答修正为自然表达 `Yes, I do.`；Drink 单元将饮品词和礼貌请求句按不同学习目标分类。
- 一年级上册 School 单元补入 Starter 附录的课堂指令和 `What’s missing?`，把问候语放回本单元，并移除不在本单元词汇范围内的 `Thank you!` 干扰项。
- 三年级上册 Food 分类题不再出现空的“饮品”组：水果与其他食物使用清楚、均有题卡的分类标准；英语高阶词义题改为利用已知词义推断另一词义，与进阶的双词核对动作区分。
- 对 32 个课程条目核对教材词汇、分类标准、例句、词序和答案；继续保证分类题每题不超过 8 张卡、超过 8 张时在两个任务中完整覆盖且不重复。
- 修复一年级上册 Numbers 单元进阶任务二的重复考点：`grade-1/term-1/english/unit-04/advanced/task-02/session-01/question-08` 改为数词顺序应用，不再与该任务 question-01 重复询问 `four` 的词义。

逐项修复 ID、原因和生成器覆盖范围已写入[逐题审校台账](grade-1-and-3-question-review.tsv)。每个条目按 `{课程 ID}/{basic|advanced|high}/task-{01|02}/session-01/question-{01..08}` 登记 48 题；生成器级问题均以受影响的题目范围和对应测试记录。

## 来源与证据边界

课程依据项目固定的 TapXWorld 快照，未将不同版本的目录或词表混用，也未将其表述为人教社最新版。英语学校开课情况仍按清单保留“未确认”。部分扫描版英语 PDF 在本次无法提取可检索文本；这些单元依据现存教材清单、`sourceTopics` 和台账中已记录的逐单元来源审查，不将本次运行时导出描述为对扫描页的重新逐页 OCR 审查。题目与讲解均为原创练习表达。

本报告确认课程数据本身、答案键和已登记教材主题范围通过本轮审校；它不证明学校实际采用该教材，也不代表人教社新版册次目录已逐页核对。
