# 课程目录与内容编写规范

本文是新增或修改课程时的单一操作入口。先按目录和数据约定录入，再核对教材范围、逐题审校并运行检查；项目当前课程范围以 `src/content/curriculum.ts` 和 `docs/curriculum/grade-2-textbook-inventory.md` 为准。

## 目录结构

可玩课程条目按年级、学期、学科、条目 slug 分层保存，每个条目使用一个 `index.ts` 入口：

```text
src/content/grade-{年级}/term-{1|2}/{chinese|math|english}/{条目 slug}/index.ts
```

条目 slug 仅使用下列形式，序号为两位数并按册次目录排列：

- `unit-NN`：教材中的编号单元，包括有编号的总复习。
- `review-NN`：未编号的复习条目。
- `integrated-practice-NN`：未编号的综合实践条目。

同一学期、同一学科共用的构建器、类型辅助或纯函数放在学科目录中，不为每个问题拆文件，也不把共用代码复制到条目目录。当前目录范例：

```text
src/content/grade-2/term-1/chinese/unit-01/index.ts
src/content/grade-2/term-1/math/integrated-practice-01/index.ts
src/content/grade-2/term-2/english/review-01/index.ts
```

## 注册与数据模型

1. 为课程建立完整、唯一的课程 ID，并在 `src/content/curriculum.ts` 注册条目及其目录类型、正式编号、成就资格和教材版本 ID。
2. 单元内容记录 `sourceTopics`，只列出所选教材清单中能够核实的知识主题；版次、来源链接、固定快照、回退原因和核验状态维护在 `src/content/textbooks.ts`。
3. 使用对应学科构建器生成任务、场次和题目 ID；不要手工修改生成器 ID 或用临时序号绕过目录顺序。规范层级为：

   ```text
   grade-N/term-N/subject/entry
   └── difficulty/task-NN/session-NN/question-NN
   ```

4. 每个可玩条目包含 `basic`、`advanced`、`high` 三档。基础档至少两个按知识目标拆分的任务；进阶和高阶各恰好两个不同任务。每个任务有清楚、可观察的学习目标和建议顺序。
5. 每个任务包含一场约 20 分钟的学习场次，每场恰好 8 道题。题目使用现有题型及答案结构；答案 ID 必须引用实际选项或条目，所有生成 ID 全局唯一。
6. 正式编号单元可以计入成就；复习或综合实践是否计入成就由真实教材目录与注册表决定，不得仅根据目录文件夹名称推测。

## 难度标准

| 难度 | 要求 | 不允许 |
| --- | --- | --- |
| 基础 | 练习一个明确知识点，采用直接辨认、一步计算或有提示的练习 | 混入未教知识、陷阱题或歧义答案 |
| 进阶 | 把已学知识迁移到熟悉的新情境，或选择方法组合两个相关知识点 | 只增加题量或数字、改换角色来冒充迁移 |
| 高阶 | 在已学范围内独立安排步骤、比较方案或解释策略 | 超年级先修知识、冷僻词、竞速压力或故意误导 |

同一条目的两个进阶任务应有不同目标或迁移情境；两个高阶任务应考查不同的策略组合。高阶提高的是规划和推理要求，不是引入更高年级知识。

## 教材来源与原创边界

- 对每册课程优先使用可完整核实的人教社公开最新版；如完整新版学生书或目录不可核实，按项目裁定使用教材清单固定的 TapXWorld 快照，并明确标记为 `tapx-fallback`。一个册次不得混用版次。
- 教材版本元数据应可追溯；来源、ISBN、版次或印次没有可靠证据时留空，不猜测。英语产品条目不代表学校已确认开设英语。
- 题目、提示、解释、鼓励反馈和配图须为原创。不得将教材 PDF、扫描页、封面、插图或大段课文复制进仓库或网页。
- 条目在来源、目录、题目和答案均完成核查前不得标记为已核验或开放。

## 逐题审校

逐条目检查全部难度、任务、场次中的旧题和新题，不只审新增题。每道题都要确认：

1. 答案唯一，答案键准确；配对、排序和分类没有遗漏或冲突。
2. 题干、提示和解释相互一致，信息完整，二年级学生能理解。
3. 知识点符合对应册次主题且没有挪用受保护教材原文。
4. 情境、词汇、单位和信息量适龄，表述自然、没有隐藏条件。
5. 题目服务于任务目标，难度确实符合所在档位。

学科检查另包括：数学逐式复算、单位与情境条件核对；英语拼写、大小写、词义和语法核对；语文字词、题意和解释准确性核对。可执行的答案校验是辅助筛查，不能替代语义审校。

在 `docs/curriculum/grade-2-question-review.tsv` 记录每个课程条目的题目总数、已审数量、各项审校状态和修复记录。发现问题时记录完整题目 ID、修改原因和状态；未审完时不得把该行标记为“完成”。

## 新增课程检查清单

1. 核对教材清单、来源类型、单元类别和 `sourceTopics`。
2. 新建规范目录与 `index.ts`，并在课程注册表中仅登记一次。
3. 依据难度标准编写各任务和题目，保证稳定 ID、答案引用、每场 8 题。
4. 逐题审校并更新中文审校台账。
5. 运行 `npx vitest run src/content/curriculumLayout.test.ts`、`npx vitest run src/content/curriculum.test.ts`、`npm run test:unit`、`npm run test:coverage`、`npm run test:e2e`、`npm run build` 和 `git diff --check`；修复失败后重跑相关检查。
6. 检查 Cloudflare Pages 静态 SPA 路由未被破坏；不要新增顶层 `404.html`。
