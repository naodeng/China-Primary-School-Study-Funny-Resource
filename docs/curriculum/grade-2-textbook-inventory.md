# 二年级教材版次与来源核对清单

**核对日期：** 2026-10-14 | **范围：** 二年级上、下学期语文、数学、英语六册

**课程决定：** 用户明确要求包含英语，并说明学校实际使用 TapXWorld 所列教材文件；同时选择“先按人教社公开最新版制作”。

**当前状态：** 这两个来源方向存在版次冲突，课程版次尚未裁定。Tasks 5–10 不得把两套目录、课文或知识顺序混用。

## 需要先裁定的版次冲突

TapXWorld 在 2025-10-18 的固定快照 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7` 中，二年级数学上册文件版权页为 2022 年印次，数学下册仍是旧目录；英语下册 PDF 文件元数据为 2020 年生成，目录含旧版主题。人民教育出版社后来发布了语文修订说明，并在 2024–2026 年持续介绍、更新新课标数学教材。所以上述 TapXWorld 文件不能一概当作人教社最新公开版。

用户已确认学校实际使用 TapXWorld 列出的文件；这一用户陈述用于识别校用来源，但它与“使用人教社公开最新版”不能自动视为同一版。请在开始课程内容录入前裁定唯一来源：

1. **对齐学校已用的 TapXWorld 文件**：按这六份文件可见的实际版次制作；文档如实注明其与人教社后续公开新版存在差异，不称为最新版。
2. **对齐人教社公开最新版**：以可核实的出版社新版为准，TapXWorld 文件只作旧版对照；出版社未公开足够目录/版本证据的册次继续标为待核，不猜目录。

英语仍按用户已明确要求纳入产品范围，标为“一年级起点预备级 / 地方课程规划选用”；在未获学校课程安排材料时，不表示该校一定开设英语。

## 目录映射和进度规则

裁定版次后，依所选版本的实际目录一条一条登记，课程 ID 按 `grade-2/term-N/subject/unit-NN` 等规范生成：

| 教材条目 | 类型 | 正式单元计数 |
| --- | --- | --- |
| 教材正式编号单元（含教材正式编号的复习与关联单元） | `unit` | 计入 |
| 未编号英语 Revision | `review` | 不计入 |
| 未编号数学综合实践活动 | `integrated-practice` | 不计入 |

每册元数据记录教材全名、版次/印次、ISBN（有证据时）、来源链接、核对日期、TapXWorld 固定提交号及核对状态。只有目录和课程内容均与最终裁定版本一致后，才能标记 `verificationStatus: verified`、开放游玩或计入成就。

教材版权内容只用于核对知识范围；网站题目、提示、讲解和配图保持原创，不复制教材扫描页、插图或大段原文。
