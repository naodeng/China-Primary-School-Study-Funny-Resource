# 二年级教材版次与来源核对清单

**核对日期：** 2026-10-14 | **范围：** 二年级上、下学期语文、数学、英语六册

**课程决定：** 用户最终裁定本项目优先按人教社公开最新版编写；TapXWorld 固定快照仅用于对照学校现用教材。英语按产品范围纳入。

**当前状态：** 课程来源已裁定为人教社截至核对日公开的最新版次。用户确认学校使用 TapXWorld 列出的教材，但该固定快照早于部分人教社修订，仅作为学校现用版本对照，不作为新版缺项的补充来源。六册的具体最新版次、版权页和目录须逐册核对；不能核实的册次标为待核，不猜目录、不开放游玩。

## 已裁定来源与版次差异

人教社公开最新版是本项目课程内容权威来源。TapXWorld 在 2025-10-18 的固定快照中收录的教材与后续人教社公开版本存在差异；用户确认学校使用这些 TapXWorld 文件，因此库存同时记录学校现用版本与出版社新版的差异。课程文案、单元结构和学习要素必须对应人教社最新可核实版次，不得从 TapXWorld 旧目录猜补或混入旧课文。

英语课程纳入产品，因为用户明确要求。人教社公开说明一、二年级设预备级供地方课程规划选用；但截至本次核对，未取得人教社最新版二年级预备级学生用书完整目录，也没有学校课表材料证明本校实际开设英语。此产品课程与校内开课状态分开记录；新版英语目录未核实前不得用 TapXWorld 旧版代替。

## 目录映射和进度规则

依人教社公开最新版各册可核实的实际目录逐条登记，课程 ID 按 `grade-2/term-N/subject/unit-NN` 等规范生成：

| 教材条目 | 类型 | 正式单元计数 |
| --- | --- | --- |
| 教材正式编号单元（含教材正式编号的复习与关联单元） | `unit` | 计入 |
| 未编号英语 Revision | `review` | 不计入 |
| 未编号数学综合实践活动 | `integrated-practice` | 不计入 |

每册元数据记录教材全名、版次/印次、ISBN（有证据时）、人教社来源链接、核对日期、TapXWorld 对照提交号及核对状态。只有新版书目、目录和课程内容均完成核实后，才能标记 `verificationStatus: verified`、开放游玩或计入成就。

教材版权内容只用于核对知识范围；网站题目、提示、讲解和配图保持原创，不复制教材扫描页、插图或大段原文。
